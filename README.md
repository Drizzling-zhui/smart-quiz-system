# 智能题库系统

纯前端单页应用，用于管理和练习题库。支持学科管理、题库浏览、答题训练、多种格式导入导出，以及本地文件夹双向同步。

## 快速开始

浏览器直接打开 `index.html` 即可使用，无需构建工具或后端服务。也可使用任意静态服务器（如 VS Code Live Server）。

数据默认存储在浏览器 `localStorage` 中。可选绑定本地文件夹实现自动备份和双向同步。

## 功能概览

### 题库管理
- **学科与文件夹树**：支持学科 → 文件夹 → 题库文件的层级结构，可拖拽调整
- **题目 CRUD**：支持单选题、多选题、判断题、填空题、简答题五种题型
- **批量导入**：文本解析、JSON 导入、文件导入（PDF / Word / 图片）三种方式
- **题目备注**：每道题可添加解题思路、记忆技巧等私人笔记

### 答题训练
- **顺序答题**：按题库顺序依次作答
- **随机答题**：打乱题目顺序出题
- **错题重刷**：只练习之前答错的题目
- **即时判分**：提交后立即显示对错、正确答案和解析
- **答题统计**：每道题记录答题次数、正确次数，展示正确率

### AI 功能（需配置 API）
- **AI 智能解析**：粘贴任意格式的题目文本，自动提取为结构化题目
- **AI 对话助手**：右侧对话面板，可针对当前题目提问，支持流式输出和快速模式
- **文件导入**：上传 PDF / Word / 图片，自动提取文字后由 AI 解析为题目

### 数据同步
- **本地文件夹双向同步**：使用 File System Access API 绑定本地目录，修改自动备份
- **导入导出**：支持 JSON 格式的导入导出，导入时自动修复不规范格式

## 技术栈

- 纯 HTML + CSS + JavaScript，零框架依赖
- `localStorage` 数据持久化
- File System Access API 本地文件同步
- 支持 OpenAI 兼容接口（DeepSeek、通义千问、豆包等）

## 使用教程

### 1. 配置 API（可选）

点击侧边栏齿轮图标进入设置，填入 API 地址、模型名称和密钥。支持所有兼容 OpenAI 格式的接口。配置后可启用 AI 智能解析、AI 对话和文件导入功能。

### 2. 导入题目

点击左侧「＋ 添加学科」创建学科，然后在学科下的题库文件上点击「＋」添加题目。也可以使用批量导入：
- **文本解析**：粘贴题目文本，使用正则或 AI 智能解析
- **JSON 导入**：粘贴 JSON 数据，系统自动修复不规范格式
- **文件导入**：上传 PDF / Word / 图片，自动提取文字后解析

### 3. 开始答题

切换到「答题模式」，选择学科和题库，设置题目数量和答题模式（顺序/随机/错题重刷），点击开始即可。

### 4. 绑定本地文件夹（可选）

在设置中选择本地 `data/subjects/` 文件夹，实现：
- 每次修改题库自动备份到本地 JSON 文件
- 用编辑器直接编辑 JSON 后，点击「一键同步」更新到前端
- 数据仅存储在本地，不上传任何服务器

## 浏览器兼容性

支持所有现代浏览器（Chrome、Edge、Firefox、Safari）。本地文件夹同步功能需要浏览器支持 File System Access API（Chrome / Edge 86+）。
