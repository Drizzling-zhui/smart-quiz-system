⚙️ 设置与使用教程

📖 使用教程

本教程位于设置页面中，随时可打开查看。

1
配置 API

在下方「API 配置」中填入接口地址、模型名称和密钥。支持所有兼容 OpenAI 格式的 API，如 DeepSeek、通义千问、豆包等。配置后可启用：

  • AI 智能解析 — 在批量导入中粘贴任意格式题目文本，AI 自动提取
  • AI 对话 — 右侧对话面板，可针对单题提问；⚡ 快速模式在对话面板中切换
  • 文件导入 — 从 PDF/Word/图片中提取题目
2
绑定本地文件夹（可选）

在下方「本地数据目录」中选择 data/subjects/ 文件夹，实现：

  • 每次修改题库自动备份到本地 JSON 文件
  • 用 VS Code 等编辑器直接编辑 JSON 后，点击「一键同步」更新
  • JSON 文件按文件树结构存放，每个题库一个文件，方便维护
3
导入题目

在题库文件上点击「＋」添加题目，或使用批量导入：

  • 文本解析 — 粘贴题目文本，正则或 AI 智能解析
  • JSON 导入 — 粘贴 JSON 数据，自动修复格式错误
  • 文件导入 — 上传 PDF / Word / 图片，自动提取文字后 AI 解析
4
答题与复习

在「答题模式」中选择顺序/随机/错题重刷，提交后即时判分。答题统计会记录每道题的正确率，错题可重刷巩固。

🔌 API 配置

配置 AI 接口后可启用智能解析，支持任意兼容 OpenAI 格式的 API。

常用：gpt-4o-mini / deepseek-chat / claude-sonnet-4-20250514

仅存储在浏览器本地，安全可控

选择本地 data/subjects/ 文件夹后：

🔐 数据同步

设置同步口令，将题库加密导出后在手机APK中解密导入。加密文件(.enc)可安全传输。

📡 局域网同步

手机与电脑在同一WiFi下时，可直连传输数据，无需手动传文件。
需要电脑端先启动服务器：python sync_server.py
