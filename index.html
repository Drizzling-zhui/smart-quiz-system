发现 AI 智能解析

你粘贴的题目文本格式多种多样，正则解析总有遗漏。
配置 AI 接口后，系统能用大模型理解任意格式的文本，
自动提取题目、选项、答案和解析。

  • 精准识别 — 无论是超星/学习通、题库文档还是截图OCR文字，AI都能理解
  • 任意格式 — 不依赖固定模板，自由排版也能正确提取
  • 兼容多种API — 支持任意 OpenAI 兼容接口（DeepSeek、通义千问、Claude、GPT等）
  • 一键导入 — 解析结果预览确认后直接入库

    • API 密钥仅存储在浏览器本地，不会上传到第三方服务器

    ⚙️ API 设置

    配置 AI 接口后可启用智能解析，支持任意兼容 OpenAI 格式的 API。

    常用：gpt-4o-mini / deepseek-chat / claude-sonnet-4-20250514

    仅存储在浏览器本地，安全可控

    OpenAI：填入 https://api.openai.com/v1/chat/completions
    DeepSeek：https://api.deepseek.com/v1/chat/completions
    通义千问：https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions
    Claude (Anthropic)：https://api.anthropic.com/v1/messages（模型填 claude-sonnet-4-20250514）
